# MoonPadel logo kit

Brand assets and rules for building anything MoonPadel (website, landing pages, registration pages, graphics). Written for Claude Code: read this file before using any asset.

| Item | State |
| --- | --- |

## Add the moon mark (one step)

1. Save the founders' moon mark as `logo/moon-mark.png`: transparent background, square, 1024 px or larger.
2. Run `python scripts/make_sizes.py` (needs `pip install pillow`). It writes favicon, app icon, Apple touch icon and Instagram profile picture to `logo/icons/`.

## The logo

Name in running text: Moon Padel. In the logo it is one word, MoonPadel, with "Moon" in Silver and "Padel" in the ice-to-electric gradient.

Full lockup, stacked and centred (see `examples/lockup.html`):

1. Moon mark, with a Space coloured disc at 80% of its size behind it carrying the blue glow `0 0 90px 16px rgba(46,139,234,0.45)`.
2. Wordmark, about 1.45x the width of the mark.
3. Tagline PLAY BEYOND: Montserrat 500, uppercase, letter-spacing 0.42em, about a quarter of the wordmark cap height.

Which version to use:

| Background | Use |
| --- | --- |
| Space #04070F or Night #0A1428 (default) | `wordmark-color.svg`, mark with glow |
| Court blue, Electric blue, or photography | `wordmark-white.svg`, mark without glow |
| White or light | `wordmark-color-on-light.svg` or `wordmark-dark.svg` |
| Small spaces (favicon, avatar, app icon) | moon mark only, never the wordmark |

Rules:

- Clear space on all sides: the height of the "M" in the wordmark.
- Minimum width: wordmark 120 px on screen, 30 mm in print. Mark 24 px.
- Dark backgrounds are the default. The brand lives at night.
- Do not stretch, rotate, recolour, outline, add shadows other than the specified glow, or change the gradient.
- Do not retype the wordmark in another font or with different spacing. Use the SVG.
- Do not place the colour wordmark on busy photos. Use white, or put a Space overlay at 60%+ behind it.
- Medal Gold #C9A24A is for winners and medals only. Never use it in the logo.

Wordmark gradient: `linear-gradient(180deg, #C4E8FF 0%, #2E8BEA 95%)`.

## Type

Montserrat (Google Fonts) everywhere.

- Headlines: 800, uppercase, letter-spacing -0.02em, line-height 0.92
- Labels and eyebrows: 700, uppercase, letter-spacing 0.24em, Ice
- Tagline style lines: 500, uppercase, letter-spacing 0.42em
- Body: 400, line-height 1.55, Silver or Muted on dark

## Moon phases (campaign device)

The moon mark fills as an event gets closer: crescent for teasers, half for the announcement, gibbous for hype, full mark with glow on match night. Build this by masking `moon-mark.png` with a CSS `mask-image`, never by redrawing the mark.

## Copy rules

- No em dashes in any copy.
- Moon Padel is an independent tournament and events brand. Do not describe it as a club, court operator or venue.
- Do not invent dates, venues, prizes or registration numbers. Use clearly labelled placeholders.
